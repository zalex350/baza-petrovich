## П. 6. Блок «Упаковка и логистика» у SAVOL

Локально работает: у всех 1 667 SAVOL-товаров, у которых в каталоге есть логистические
ключи, логистика загружена и блок на странице есть. Из 25 случайных SAVOL-страниц блока
нет на двух — у них в каталоге логистики нет вообще:

- `SAVOL-S-А06831` (в артикуле кириллическая «А») — в каталоге только «Производитель»;
- `SAVOL-SM01-8` — в каталоге только «Материал».

На стенде блок не появится, пока там не выполнен импорт: признак «логистика»
(`attributes.is_logistics`) ставит `catalog:import-db`.

Блок выводится в `resources/views/product.blade.php` через
`rescue(fn () => $product->specRows('logistics'), collect())` — при ошибке он молча
пропадёт; при проверке ошибок не было.
