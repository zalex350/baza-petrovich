# SEO и аналитика (Google Ads, GA4, Метрика, Clarity)

Что сделано в коде и что нужно настроить руками в Google, Яндексе и админке сайта.

## 1. Что работает само

### SEO

| Что | Где в коде | Как проверить |
|---|---|---|
| `/sitemap.xml`: главная, каталог, разделы с товарами, товары (с фото), подборки, услуги, страницы, работы, отзывы. Кэш — 1 час | `SeoController::sitemap` | открыть `/sitemap.xml` |
| `/robots.txt`: закрыты корзина, заказ, кабинет, поиск, админка, API, сортировка и вид списка; ссылка на карту | `SeoController::robots`, `Seo::PRIVATE_PATHS` | открыть `/robots.txt` |
| Стенд и локальная машина закрыты от индексации (`Disallow: /`, `noindex` на всех страницах) | `config/seo.php` → `SEO_INDEX` | на стенде `SEO_INDEX=false`, на боевом — `true` |
| `<title>` и `description`: разделы и товары — по шаблонам из «Настроек» → SEO (с ценой, «от …» у раздела, числом товаров, городом), свои — в карточке раздела и товара | `App\Support\SeoTemplates` | «Сейчас: …» в форме раздела/товара |
| `canonical`: адрес без параметров; `?page=N` сохраняется; метки рекламы (`utm_*`, `gclid`) отбрасываются | `App\Support\Seo::canonicalUrl` | исходный код страницы |
| Фильтры и сортировка — `noindex, follow` (дубли не попадают в индекс, ссылки на товары — да) | `Seo::isIndexable` | `/catalog/…?sort=…` |
| Open Graph: заголовок, описание, фото товара / раздела / работы, иначе `public/images/og-default.jpg` | `partials/seo` | отправить ссылку в Telegram/Viber |
| schema.org (JSON-LD): Organization + филиалы Минск и Брест (HardwareStore, адреса, часы), WebSite с поиском, Product с ценой BYN и наличием, BreadcrumbList, FAQPage, Service | `App\Support\SeoSchema`, `config/seo.php` → `organization` | [Rich Results Test](https://search.google.com/test/rich-results) |
| Тексты разделов и «Частые вопросы» (12 разделов) под списком товаров | `database/data/petrovich/seo_content.php`, `petrovich:seo` | страница раздела, низ |
| Описания товаров без описания (по шаблону: раздел, 3 характеристики, назначение, доставка) — ждут одобрения | `petrovich:seo --products` | админка «Товары» → «Описание: не одобрено» |

### Аналитика

| Что | Где |
|---|---|
| Счётчики подключаются, как только в «Настройках» → «Аналитика и реклама» заполнен ID: Google Tag Manager, или GA4 + Google Ads напрямую (gtag.js), Яндекс Метрика с Вебвизором, Microsoft Clarity | `partials/analytics`, `resources/js/analytics.js` |
| Не считаются: админка и визиты администраторов | `App\Support\Analytics::config` |
| Consent Mode v2 и баннер cookie: «Уведомление» (по умолчанию — счётчики работают сразу) / «Согласие» (до «Принять» Google без cookie, Метрика и Clarity не грузятся) / «Без баннера» | «Настройки» → «Согласие на cookie» |
| Источник визита: `utm_*`, `gclid`, `yclid`, сайт-источник, страница входа — cookie на 30 дней, сохраняется в заказ и заявку, видно в админке, уходит в Битрикс24 (поля UTM_*) | `App\Support\Attribution`, `CaptureAttribution` |

**События** (формат GA4; в `dataLayer` для GTM — `{event, ecommerce}`):

| Событие | Когда | Данные |
|---|---|---|
| `view_item` | карточка товара | товар, цена |
| `view_item_list` | раздел, «Акции», «Новинки», «Хиты» | до 20 товаров страницы |
| `add_to_cart` | «В корзину» (без перезагрузки) | товар, количество, сумма |
| `view_cart` | корзина | позиции, сумма |
| `begin_checkout` | первое касание формы оформления | позиции, сумма |
| `purchase` | страница заказа сразу после оформления (один раз на заказ) | номер (`transaction_id`), сумма с НДС, НДС, позиции, оплата, получение |
| `generate_lead` | отправлена заявка («Узнать цену», «Заказать услугу», «Обратный звонок») или квиз | `lead_type`, `quiz_id` |
| `click_phone`, `click_email`, `click_messenger` | клик по телефону, почте, Viber/Telegram/WhatsApp | где на странице: header, footer, content |
| `cookie_consent` | выбор в баннере | granted / denied |

Без GTM `purchase` и `generate_lead` ещё и отправляются как **конверсии Google Ads** (метки — в «Настройках»),
все события — как **цели Метрики** (`reachGoal`) и события Clarity.

**«Куда зашли, сколько были, где ушли»** — в GA4 без доп. настройки:
«Отчёты → Вовлечённость → Целевая страница» (вход), «Страницы и экраны» (просмотры, среднее время вовлечения,
выходы), «Исследования → Анализ пути» (переходы и выход). Записи визитов и тепловые карты — Вебвизор Метрики
и Microsoft Clarity (бесплатно).

## 2. Настроить после деплоя

1. **`.env` боевого сервера**: `APP_URL=https://baza-petrovich.by`, `SEO_INDEX=true` (на стенде — `false`).
2. **Миграции и тексты**: `php artisan migrate`, `php artisan petrovich:seo` (тексты разделов),
   по желанию `php artisan petrovich:seo --products` — описания товарам, затем просмотреть и одобрить
   в админке (или сразу `--approve`).
3. **Google Search Console** → добавить ресурс → «Тег HTML» → вставить тег в «Настройки» → SEO →
   «Google Search Console» (можно весь тег) → Подтвердить → «Файлы Sitemap» → `sitemap.xml`.
4. **Яндекс Вебмастер** — так же: мета-тег → «Настройки», затем «Индексирование → Файлы Sitemap».
5. **GA4**: создать ресурс и веб-поток → ID `G-…` в «Настройки». В GA4 отметить ключевыми событиями
   (Администратор → События) `purchase` и `generate_lead`; при желании `click_phone`, `click_messenger`.
6. **Google Ads**: «Цели → Конверсии → Новое действие → Сайт» → вручную два действия: «Покупка»
   (ценность — из события, учитывать «Каждую») и «Заявка» (ценность 1, «Одну») → в «Настройки» ID `AW-…`
   и метки (часть после `/` в `send_to`). Связать Google Ads с GA4 (Администратор GA4 → Связи с Google Ads)
   и включить автопометку (gclid) в аккаунте Ads.
   - Вариант через **Tag Manager**: в «Настройки» только `GTM-…`, поля GA4 и Ads пустые; в контейнере —
     тег «Google: конфигурация GA4», теги событий GA4 по триггерам «Специальное событие» (имена — из таблицы выше,
     параметры — `ecommerce`), тег «Конверсия Google Ads» на `purchase` (ценность `ecommerce.value`,
     ID транзакции `ecommerce.transaction_id`) и на `generate_lead`, «Связывание конверсий».
7. **Метрика**: создать счётчик (Вебвизор включится сам) → номер в «Настройки». Цели «JavaScript-событие»:
   `purchase`, `generate_lead`, `click_phone`, `add_to_cart`.
8. **Clarity**: создать проект → ID в «Настройки».
9. **Политика cookie**: опубликовать страницу со slug `privacy` (админка «Страницы») — баннер покажет ссылку «Подробнее».
10. **Координаты складов** для карт в разметке — `config/seo.php` → `organization.branches.*.geo`.

## 3. Чего нет (следующие шаги)

- **Редиректы со старого сайта** (старые адреса товаров и разделов → новые) — отдельная задача.
- **ЧПУ товаров** (`/product/{id}` → `/product/{slug}`) — вместе с редиректами.
- **Фид для Google Merchant Center** (товары в Shopping/Performance Max) — разметка Product уже есть,
  фид XML можно добавить по шаблону `sitemap`.
- **Офлайн-конверсии** (заказ подтверждён/оплачен в CRM → Google Ads по `gclid`) — `gclid` уже сохраняется в заказе.
