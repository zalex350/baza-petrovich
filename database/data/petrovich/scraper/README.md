# Сбор каталога с baza-petrovich.by

Скрипты, которыми собран `../catalog.json` (Python 3, без зависимостей кроме `openpyxl` для xlsx.py).

```bash
python3 crawl.py OUT/crawl                  # обход каталога, услуг и инфо-страниц (≈820 страниц, пауза 0,25 с)
python3 parse.py OUT/crawl                  # товары из карточек и таблиц разделов → OUT/crawl/products.json
python3 desc.py OUT/crawl OUT/desc.json     # описания товаров, разделов, услуг (HTML)
python3 bundle.py OUT/crawl ../catalog.json OUT/desc.json   # каталог для php artisan petrovich:import
python3 xlsx.py OUT/crawl nomenklatura.xlsx # номенклатура для просмотра в Excel
```

Особенности исходного сайта, учтённые в разборе:
- товар бывает в нескольких таблицах (спецпредложения) — берётся таблица ближайшего раздела с колонкой «Ед.изм»;
- у части подразделов шапка таблицы скопирована с другой («Размер», «от 5 листов») — значения «м.п.», «шт» считаются единицей;
- «/» внутри имени в адресе (`polosa-stalnaya-g/k`) — категорией считается только префикс со своей страницей;
- «Цена со скидкой от 100 кг» — цена от объёма, сохраняется характеристикой, а не скидкой.
